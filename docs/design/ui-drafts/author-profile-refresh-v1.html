DESIGN NOTE

让作者身份先被认出，让内容更快进入阅读。

首屏保留头像、昵称和私信入口，但缩短装饰性留白。危险操作不抢主视觉，帖子改为连续阅读流。

  1. 01身份抬头左对齐。长昵称自然换行，头像与名称形成同一视觉组。
  2. 02单一主操作。“私信”保持明确；拉黑进入右上更多菜单，减少首屏红色冲突。
  3. 03帖子不再逐张套卡片。分隔线与频道、时间、互动信息共同建立扫描节奏。
  4. 04真实状态优先。空态、分页、失败和不可用作者继续使用现有业务语义，不新增统计或公开账号信息。
