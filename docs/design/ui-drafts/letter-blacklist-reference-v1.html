致同学的一封信

同学，你好：

欢迎来到 SpeechFUL，一个自由说话的地方。

一门课程的体验，一家值得推荐的饭店，一次寻找搭子的尝试，或是一件困扰自己的事情，都可以在这里聊聊。校园生活里有许多的事，我们想为这些声音留出位置。

我们希望，匿名能让表达轻松一些。你可以用自己选择的名字，分享经历、提出疑问，倾诉一些自己独特的感受。

让世界多一些爱与真诚，这是我们写在 SpeechFUL 里的愿望。

谢谢你来到这里。
