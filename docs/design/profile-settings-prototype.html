我的 / 设置

SpeechFUL · 交互原型 v1 · 纯前端假数据

可以点什么

  • 左上角齿轮 → 设置（从左往右滑入）
  • 在“我的”上半部分右滑 → 进入设置
  • 内容区左右滑 → 切换五个页签；帖子栏再右滑 → 设置
  • 点击页签切换同样有滑动动画
  • 右上身份胶囊 → 切换身份
  • 设置头像 / 编辑信息 → 底部弹层
  • 五个内容页签、点赞、收藏
  • 设置 → 主题：浅色 / 深色 / 跟随系统
  • 账号资料里的编号可复制

这一版的改动

取消“我的”标题与首页左滑设置入口；个人区参考所给图片但去掉右上按钮，操作缩小为两枚胶囊；内容卡片改为扁平分隔样式。

本轮更新

「设置图片」改为「设置头像」：弹层内直接展示系统相册网格，选择照片后进入头像编辑界面（圆形裁切、确认，不合规提示在界面内显示）；此为目标样式，当前版本先直达系统照片选择器，内嵌相册后期实现。「编辑信息」只保留昵称编辑，不再显示账号信息与相关入口。设置新增「字体大小」：小／标准／大／特大四档，切换后全局立即生效。

说明

所有数据为本地假数据，不联网。深浅色切换立即生效，可用来评审两种观感。
